-------------------------------------------------------------------------------
To Build the new MSYS DLL:

1. Download and install the 64-bit Git for Windows SDK from the Git for Windows website. Install it to a convenient location such as:

 G:\git-sdk-64

2. Open:

 G:\git-sdk-64\msys2_shell.cmd

3. Install the build dependencies. In the new shell window:

 pacman -S --needed msys2-devel base-devel autotools cocom diffutils gcc gettext-devel libiconv-devel make mingw-w64-cross-crt mingw-w64-cross-gcc mingw-w64-cross-zlib perl zlib-devel xmlto docbook-xsl libzstd-devel

4. Clone the forked repo with the MSYS fix:

 git clone https://github.com/safmswork/msys2-runtime.git /g/gfw-msys

5. In a Powershell window, build the new MSYS DLL:

 For a first time run, use this command:
 PS G:\gfw-msys>  & 'G:\git-sdk-64\usr\bin\bash.exe' -lc 'export PATH=/usr/bin:/mingw64/bin:/mingw32/bin:$PATH; cd /g/gfw-msys && (cd winsup && ./autogen.sh) && ./configure --disable-dependency-tracking --with-msys2-runtime-commit="$(git rev-parse HEAD)" && make -j8'

 Afterwards use this much faster build command:
 PS G:\gfw-msys> & 'G:\git-sdk-64\usr\bin\bash.exe' -lc 'export PATH=/usr/bin:/mingw64/bin:/mingw32/bin:$PATH; cd /g/gfw-msys && make -C x86_64-pc-cygwin/winsup/cygwin -j8 new-msys-2.0.dll'

6. Confirm the new MSYS DLL was built

 Look here to ensure the new DLL was built G:\gfw-msys\x86_64-pc-cygwin\winsup\cygwin\new-msys-2.0.dll

-------------------------------------------------------------------------------
On the test machine:

1. Install Git for Windows normally, using the standard installation location:

 winget install --id Git.Git --exact --source winget

2. Replace the downloaded MSYS DLL with the new one we created earlier. This will require renaming from new-msys-2.0.dll to msys-2.0.dll. NOTE: If you are doing this test on a VM this is a good time to create a checkpoint.

 Downloaded location: C:\Program Files\Git\usr\bin\msys-2.0.dll

3. Install Copilot CLI as the interactive user. If using another agent system (Claude Code), install that system and ignore this step:

 winget install --id GitHub.Copilot --exact --source winget --scope user

4. Enable Sandboxing. If using another agent system (Claude Code), enable sandboxing on that system as appropriate:

 Start Copilot and use  /sandbox  to ensure sandboxing is enabled. Do not enable bypass or allow-all modes.

5. If using Copilot, launch Copilot from "C:\Program Files\Git" . This allows Copilot to launch VIM directly without having to use a shell intermediary (ex. pwsh) which would fail from within a sandbox.

6. Try to launch VIM.exe from within the sandbox. This should now succeed. Here is an example prompt to launch VIM from within Copilot:

 Run this exact command once using the sandboxed shell. Do not wrap it in pwsh.exe, cmd.exe, or another shell. Do not retry or bypass the sandbox. Report the complete output and exit code:

 & '.\usr\bin\vim.exe' --version
